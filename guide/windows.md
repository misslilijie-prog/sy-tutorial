# 速云 Windows 客户端安装与使用教程

::: danger 重要提醒
不要在速云 App 内付款！！！否则秒封号
:::

速云 Windows 客户端支持一键连接上网，下载安装后输入账号密码即可使用，安装过程简单快速。

::: tip
强烈建议 Windows 用户使用 Chrome 或 Edge 浏览器访问外网，兼容性和速度更优。
:::

## 一、下载方式

- 下载地址：[https://zip.suyungo.de/](https://zip.suyungo.de/)
- 下载文件名：`速云网络windows端.zip`

也可去官网下载：进入速云官网 → 左侧菜单「使用文档」 → 选择「Windows端」即可找到下载链接。

<img src="https://img.mimy.cc/suyunapp111.webp" alt="下载示例" />

## 二、安装步骤

### 1. 下载安装包

将速云应用程序下载到电脑上，双击进行安装。

<img src="https://img.mimy.cc/suyunapp222.webp" alt="下载安装包 01" />
<img src="https://img.mimy.cc/suyunapp333.webp" alt="下载安装包 02" />
<img src="https://img.mimy.cc/suyunapp444.webp" alt="下载安装包 03" />

### 2. 绕过系统提示

若安装过程中出现 Windows 安全提示，点击「更多信息」→「仍要运行」。

<img src="https://img.mimy.cc/suyunapp555.webp" alt="安全提示 01" />
<img src="https://img.mimy.cc/suyunapp666.webp" alt="安全提示 02" />
<img src="https://img.mimy.cc/suyunapp777.webp" alt="安全提示 03" />

### 3. 登录速云账号

打开速云应用后，输入账号和密码登录。

<img src="https://img.mimy.cc/suyunapp888.webp" alt="登录界面 01" />
<img src="https://img.mimy.cc/suyunapp999.webp" alt="登录界面 02" />

### 4. 选择节点并连接

登录成功后，在应用中选择需要使用的节点线路，点击「连接」。

<img src="https://img.mimy.cc/suyunapp1010.webp" alt="选择节点并连接" />

### 5. 连接成功，开始使用

当显示已连接状态后，即可正常使用速云服务。

## 三、注意事项

::: warning
- 首次运行时如遇到系统拦截提示，务必点击「允许」或「仍要运行」
- 建议从官网或官方渠道下载，以保证应用版本安全与更新
- 登录时请确认账号密码输入正确，避免频繁错误导致账号暂时锁定
:::
