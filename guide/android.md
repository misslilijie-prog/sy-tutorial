# 速云 Android 客户端安装与使用教程

::: danger 重要提醒
不要在速云 App 内付款！！！否则秒封号
:::

速云安卓客户端支持一键连接上网，下载安装后输入账号密码即可使用，安装过程简单快速。

强烈建议安卓用户使用 Chrome 或 Edge 浏览器访问外网，兼容性和速度更优：

| 浏览器 | 下载地址 | 大小 |
| :--- | :--- | :--- |
| Chrome | [https://url.mimy.cc/chrome](https://url.mimy.cc/chrome) | 150MB |
| Edge | [https://url.mimy.cc/edge](https://url.mimy.cc/edge) | 190MB |
| Firefox | [https://url.mimy.cc/fox](https://url.mimy.cc/fox) | 325MB |

## 第一步：下载速云安卓 APP

- 下载地址：[https://zip.suyungo.de/](https://zip.suyungo.de/)
- 下载文件名：`速云网络安卓端.zip`

::: warning 注意
下载后请勿直接点击安装，建议先到文件管理中找到安装包再执行安装步骤。
:::

也可去官网下载。

<img src="https://img.mimy.cc/azsuyunp111.webp" alt="安装包下载截图" />

## 第二步：打开文件管理，开始安装

1. 打开手机的文件管理或下载管理
2. 找到刚刚下载的速云安装包（通常为 `.apk` 文件）
3. 点击开始安装（如遇到提示"禁止安装未知来源应用"，请进入设置授权）

## 第三步：打开 APP 并登录

1. 安装完成后，在手机桌面找到速云 APP 图标
2. 打开应用，输入账号和密码登录

<img src="https://img.mimy.cc/azsuyunp666.webp" alt="登录截图 01" />
<img src="https://img.mimy.cc/azsuyunp777.webp" alt="登录截图 02" />

## 第四步：选择节点并连接网络

1. 登录后进入主界面
2. 在节点列表中选择任意线路
3. 点击下方的"连接"按钮
4. 成功连接后即可访问外网

<img src="https://img.mimy.cc/azsuyunp888.webp" alt="节点截图 01" />
<img src="https://img.mimy.cc/azsuyunp999.webp" alt="节点截图 02" />

## 教程结束

现在你已经成功在安卓端安装并登录速云 APP，连接节点即可访问外网。
